# Print a MaGP Bayesian optimization result

Print a MaGP Bayesian optimization result

## Usage

``` r
# S3 method for class 'magp_bayes_opt'
print(x, ...)
```

## Arguments

- x:

  A `magp_bayes_opt` object returned by
  [`magp_bayes_optimize()`](https://twskr.github.io/magp/reference/magp_bayes_optimize.md).

- ...:

  Unused.

## Value

`x`, invisibly.
