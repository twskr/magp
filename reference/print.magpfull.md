# Summarize a fitted full-mapping MaGP model

Prints the mapping dimension, model size, nugget variance, fitted mean,
objective value, and optimizer status.

## Usage

``` r
# S3 method for class 'magpfull'
print(x, ...)
```

## Arguments

- x:

  A `magpfull` model returned by
  [`magpfull_fit()`](https://twskr.github.io/magp/reference/magpfull_fit.md).

- ...:

  Unused.

## Value

`x`, invisibly.
