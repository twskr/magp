# Summarize a fitted two-dimensional MaGP model

Prints the model size, nugget variance, fitted mean, objective value,
and optimizer status.

## Usage

``` r
# S3 method for class 'magp2d'
print(x, ...)
```

## Arguments

- x:

  A `magp2d` model returned by
  [`magp2d_fit()`](https://twskr.github.io/magp/reference/magp2d_fit.md).

- ...:

  Unused.

## Value

`x`, invisibly.
