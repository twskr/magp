# Print a MaGP acquisition-search result

Print a MaGP acquisition-search result

## Usage

``` r
# S3 method for class 'magp_next_point'
print(x, ...)
```

## Arguments

- x:

  A `magp_next_point` object returned by
  [`magp_next_point()`](https://twskr.github.io/magp/reference/magp_next_point.md).

- ...:

  Unused.

## Value

`x`, invisibly.
