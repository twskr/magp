# Start Bayesian optimization from a generated initial design

Constructs a quantitative-sequence initial design, evaluates a
user-supplied objective at every initial run, and continues with
sequential MaGP Bayesian optimization.

## Usage

``` r
magp_bayes_optimize_from_scratch(
  FUN,
  n_initial,
  q,
  model = c("2d", "full"),
  direction = c("minimize", "maximize"),
  n_iter = 10L,
  xi = 0,
  stop_ei = 0,
  stop_patience = 3L,
  seed = NULL,
  design_control = list(),
  fit_control = list(),
  acquisition_control = list(),
  objective_args = list(),
  verbose = TRUE
)
```

## Arguments

- FUN:

  Objective function. It is called with one named argument for each
  input column. It must return one finite numeric value or a list
  containing a finite numeric `Score` or `Value` component.

- n_initial:

  Number of runs in the generated initial design.

- q:

  Number of components. Must be at least three.

- model:

  Sequence mapping used by the surrogate: `"2d"` or `"full"`.

- direction:

  Whether `FUN` is being minimized or maximized.

- n_iter:

  Maximum number of sequential evaluations after the initial design has
  been evaluated.

- xi:

  Nonnegative exploration offset for expected improvement.

- stop_ei:

  Nonnegative absolute expected-improvement threshold.

- stop_patience:

  Positive whole number of consecutive low-EI evaluations required for
  early stopping.

- seed:

  Optional nonnegative whole-number seed. It controls the initial
  design, model fitting, sequence sampling, acquisition starts, and any
  random values generated by `FUN`, without changing the caller's
  random-number state.

- design_control:

  Named list of additional arguments for
  [`magp_initial_design()`](https://twskr.github.io/magp/reference/magp_initial_design.md),
  such as `sequence_maxit`, `quantity_maxit`, and `alignment_maxit`.
  `n`, `q`, and `seed` are managed by this function.

- fit_control:

  Named list of additional arguments for
  [`magp2d_fit()`](https://twskr.github.io/magp/reference/magp2d_fit.md)
  or
  [`magpfull_fit()`](https://twskr.github.io/magp/reference/magpfull_fit.md).
  `X`, `y`, and `seed` are managed by this function.

- acquisition_control:

  Named list of additional arguments for
  [`magp_next_point()`](https://twskr.github.io/magp/reference/magp_next_point.md).
  The fitted model, direction, exploration offset, reference value, and
  seed are managed by this function.

- objective_args:

  Named list of fixed additional arguments supplied to `FUN` after the
  generated input columns.

- verbose:

  Logical; if `TRUE`, print one line for every initial and sequential
  objective evaluation.

## Value

An object of class `magp_bayes_opt`. In addition to the components
returned by
[`magp_bayes_optimize()`](https://twskr.github.io/magp/reference/magp_bayes_optimize.md),
it contains `initial_design`, `initial_response`, `initial_evaluations`,
`design_control`, and `started_from_initial_design`.

## Details

The generated input columns are named `quantity_1` through `quantity_q`
and `sequence_1` through `sequence_q`. The same named-argument objective
interface is used for the initial and sequential evaluations.

Use
[`magp_bayes_optimize()`](https://twskr.github.io/magp/reference/magp_bayes_optimize.md)
instead when completed initial experiments and their responses are
already available.

## Examples

``` r
# \donttest{
objective <- function(quantity_1, quantity_2, quantity_3,
                      sequence_1, sequence_2, sequence_3) {
  quantities <- c(quantity_1, quantity_2, quantity_3)
  sequence <- c(sequence_1, sequence_2, sequence_3)
  -sum((quantities - c(0.2, 0.6, 0.8))^2) -
    0.01 * sum((sequence - c(1, 3, 2))^2)
}
result <- magp_bayes_optimize_from_scratch(
  objective,
  n_initial = 6,
  q = 3,
  direction = "maximize",
  n_iter = 1,
  seed = 1,
  design_control = list(
    sequence_maxit = 100,
    quantity_maxit = 100,
    alignment_maxit = 100
  ),
  fit_control = list(maxeval = 100),
  acquisition_control = list(n_starts = 2, maxit = 20)
)
#> initial run 1 value -0.891944

#> initial run 5 value -0.603056 
#> initial run 6 value -0.354167 
#> iteration 1 value -0.44 EI 2.16543 
result$best_point
#> quantity_1 quantity_2 quantity_3 sequence_1 sequence_2 sequence_3

result$best_value
```
